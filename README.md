# Smart Fridge Roast

One original line roasting the smart fridge I share a house with, written
for the [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/c/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9)
competition on [make.fun](https://make.fun).

## The line

> My fridge filmed me eating ice cream at 2am for six months and now leaves the light on, like a disappointed parent with Wi-Fi.

126 characters, one line, no clichés: a real smart-fridge behaviour (its
internal camera watching the midnight snack run) with a sharp last word.

## Run

```sh
node main.ts            # writes the line to /output/entry.txt
node main.ts entry.txt  # or to a path of your choice
```

Node 22 or later, standard library only, deterministic — the same bytes on
every run.
